语境词典 Context Dictionary

拍下你正在读的内容，查词时结合上下文，用中文解释词义。

如何使用

  1. 点击「添加页面」，拍照或从相册选择你正在阅读的页面，可以添加多页。
  2. 文字识别在手机本地完成，可点开页面查看和修改识别结果。
  3. 在底部输入要查的词，应用会结合原文，用中文解释它在这里的意思。

为什么需要 OpenAI API Key？

解释由 OpenAI 的模型生成。本应用免费，不设服务器，直接使用你自己的 API Key 调用 OpenAI，费用由你的 OpenAI 账户承担（使用默认的小模型时，每次查词通常不到一分钱人民币）。

  1. 登录 platform.openai.com/api-keys，创建一个 API Key。
  2. 在应用中点击右上角齿轮 → 粘贴 Key → 「测试连接」。

Key 只保存在你手机的钥匙串中，不会发送给开发者。

常见问题

提示 401：API Key 无效或已被删除，请重新创建。
提示 429：OpenAI 账户额度不足或请求过于频繁，请检查账户余额。
提示 404：模型名称不可用，请在设置中点「恢复默认」。

English

Context Dictionary lets you photograph the page you are reading and look up any word. The explanation is written in Chinese and is based on the surrounding text. The app is free and uses your own OpenAI API key. For help or feedback, open an issue on GitHub.
