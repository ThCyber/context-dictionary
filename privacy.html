隐私政策

语境词典 Context Dictionary · 生效日期：2026 年 10 月 7 日

概要

开发者不收集、不存储、不出售你的任何个人信息。本应用没有账号系统，没有广告，没有数据分析或跟踪工具。

照片与文字识别

你拍摄或选择的照片只在手机本地处理，文字识别使用 Apple 的系统功能在设备上完成。照片本身不会被上传到任何地方。

发送给 OpenAI 的内容

当你查词时，应用会把识别出的页面文字（最多约 6000 个字符）和你要查的词，通过你自己的 API Key 直接从手机发送到 OpenAI 的 API，用于生成解释。第一次查词前，应用会征求你的同意，你也可以随时在设置中关闭。这些内容由 OpenAI 依据其隐私政策处理；开发者无法看到这些内容。

API Key

你的 OpenAI API Key 只保存在本机的 iOS 钥匙串中，仅用于向 OpenAI 发送请求，不会发送给开发者或其他任何人。

本地数据

页面文字和查词结果只保存在内存中，点击「新阅读」或关闭应用后即被清除。应用设置（模型名称、是否同意数据共享）保存在本机。

儿童

本应用不面向 13 岁以下儿童，也不会有意收集儿童信息。

变更与联系

如本政策有更新，将在此页面公布。如有疑问，请在 GitHub 联系我们。

English summary

The developer collects no personal data. There are no accounts, ads, analytics or tracking. Photos are processed on your device and are never uploaded. When you look up a word, the recognized page text (up to about 6,000 characters) and the word are sent directly from your device to the OpenAI API with your own API key, after you have agreed to this in the app. OpenAI handles that data under its privacy policy. Your API key is stored only in the iOS Keychain on your device. Reading sessions stay in memory and are deleted when you start a new reading or close the app. The app is not directed at children under 13. Contact: GitHub issues.
